# Sample Analytical Dataset

Small CSV previews (up to 200 rows each) of the final, cleaned star-schema
tables, generated by `python -m src.storage.export_sample_dataset`. This is
a deliverable preview, not the full dataset - the full generated warehouse
(`data/warehouse/retail.duckdb`, `data/raw/*.csv`) stays out of git per
`.gitignore`; regenerate it locally with:

```bash
python src/data_generator.py
python src/transformation/data_cleaning.py
python src/transformation/build_schema.py
```

## Files

| File | Source table | Notes |
|------|--------------|-------|
| `dim_customer_sample.csv` | `dim_customer` | Phone/email are masked (same logic as the API's `analyst` role - see `docs/STORAGE.md`), since this file is committed to the repo rather than served behind a role check. SCD Type 2 fields (`valid_from`/`valid_to`/`is_current`/`version`) included. |
| `dim_product_sample.csv` | `dim_product` | |
| `dim_store_sample.csv` | `dim_store` | All 50 stores (small enough to include in full). |
| `dim_date_sample.csv` | `dim_date` | First 200 days of the 2024 calendar. |
| `fact_sales_sample.csv` | `fact_sales` | |
| `fact_inventory_sample.csv` | `fact_inventory` | Daily stock snapshots (full table is ~4.55M rows - `data/raw/inventory.csv` x 50 stores x 500 products x ~182 days). |
| `fact_shipments_sample.csv` | `fact_shipments` | `delivery_time`/`on_time_flag` are derived, not raw source columns - see `src/storage/populate_shipments.py`. |

All customer/product/store names are synthetic (Faker-generated in
`src/data_generator.py`), not real people or businesses.
